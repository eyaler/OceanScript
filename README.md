# Rendered videos

This orphan branch holds the videos produced by the OceanScript pipeline
(branch `claude/markdown-ocean-animation-pipeline-9truqa`).  Download a file
with the "Download raw file" button on GitHub, or clone just this branch:

    git clone --branch renders --single-branch --depth 1 <repo-url> renders

| file | what |
| --- | --- |
| `caspion/caspion.en.mp4` | Caspion the Little Fish, English voices, soft English subtitle track, 1280x720, 2:44 |
| `caspion/caspion.he.mp4` | the same frames with a Hebrew title card, Hebrew voices and a Hebrew subtitle track |
| `caspion/caspion.v1-burnt-subtitles.mp4` | the first render (2:12, burnt-in English subtitles, no audio) |
| `great-journey/great-journey.mp4` | "Caspion's Great Journey" asset demo (pelican, bubble, 2D city, sprite, glTF boat, clip, credits, music) |

Every later render is added here as a new commit.
