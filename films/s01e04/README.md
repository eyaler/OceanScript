# S01E04 · בגדי החג החדשים של כספיון

ערב ראש השנה. אמא ואבא עורכים את שולחן החג, אבל כספיון לא רוצה להתקלח ולא רוצה
ללבוש בגדי חג ("אנחנו דגים, אני כבר רטוב"), ונשאר בפיג'מה. דותן מגיע לארוחה
לבוש יפה, עם חולצה לבנה, פפיון זהב וכיפה, וכספיון מתרצה: מקלחת מהירה, חולצה,
פפיון אדום וכיפה כחולה. הפרק נגמר בהרמת כוסית, ודותן מברך: "שנהיה לראש של דג
ולא לזנב של דג".
